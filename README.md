# 🎬 YouTube Clone

React kullanılarak geliştirilmiş modern bir **YouTube Clone** uygulamasıdır.  
Kullanıcılar videoları listeleyebilir, arama yapabilir ve video detaylarını görüntüleyebilir.

Uygulama modern **React component mimarisi**, **API veri çekme** ve **responsive tasarım** prensipleri kullanılarak geliştirilmiştir.

# 📦 Installation

Projeyi çalıştırmak için:

```bash
git clone https://github.com/Rumeysapat/YoutubeClone.git
```

```bash
cd YoutubeClone
```

```bash
npm install
```

```bash
npm run dev
```
